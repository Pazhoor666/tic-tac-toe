# Tic Tac Toe

A single-file browser game of tic tac toe drawn on graph paper.

## Play

Open `tic-tac-toe.html` in any modern browser. No build step or server needed.

## Features

- **vs Computer** with two levels: *Easy* (often random) and *Unbeatable* (minimax)
- **2 Players** on the same screen
- Running score shown as tally marks; the opening player alternates each round
- Keyboard play with keys 1–9 (top-left to bottom-right)
- Light and dark themes follow your system setting
